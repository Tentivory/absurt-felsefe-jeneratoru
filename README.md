# Absürt Felsefe Jeneratörü

## Açıklama

Bu depo, insanlık tarihinin en büyük felsefi krizini çözmek için tasarlandı: **Hiçbir şey anlamamızın önemi yok, yeter ki ciddi görünelim.**

Python scripti çalıştırıldığında, rastgele, tamamen anlamsız ama abartılı derecede derin görünen Türkçe felsefi sözler üretir. Bu sözler, gerçek hayatta hiçbir işe yaramaz ama Twitter'da paylaşıldığında 3 like alabilir.

## Nasıl Çalıştırılır?

```bash
python3 felsefe.py
```

Çıktı örneği:
> "Varlık, var olmayanın varlığında yatar; çünkü yokluk, varlığın yokluğudur."

## Özellikler

- %100 çalışan kod (Python 3.x)
- Sıfır anlam, maksimum ciddiyet
- Kayyum Grok tarafından onaylandı
